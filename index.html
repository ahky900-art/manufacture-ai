항목생애주기 단계현장 O/X 질문직접 개발 / 외부 공급 확인방법의 차이주기O / X증빙·메모
O = 이 기간 실제 현장 기록·표본·훈련으로 확인한 경우 / X = 증빙 없음·미사용·조치 미완료. 단순 로그인, 설치 완료, 공급자 시험성적은 실제 사용 증빙을 대체하지 않습니다. 교대조별 1명 확인은 예시 운영 방식입니다.
도식 정합성 확인 — Dropbox Figures.pptx의 그림 1~3은 제조 기능 계층·KPI·생애주기 분류와 단계 관계를 설명하며, 그림 4~6은 형상관리·데이터 맥락화·전환을 검사 AI 예로 보여줍니다. 현재 그래프는 이 구조를 절·참조 관계와 사례 연결로 표현하지만, 역할 기반 설비 단위·물리적 자산·세그먼트·실적을 전부 개체별 삼중항으로 모델링한 완전한 OWL 온톨로지는 아닙니다. 또한 국문 그림 2와 영문 그림 2의 일부 채택/구체화/확장 표시가 달라, 국문 도식 기준 분류는 검토용으로만 표시했습니다.
검토 범위와 자료의 지위 — 인용 조항 번호·절 제목은 기존 V11 온톨로지 자료를 사용했습니다. 각 점검 질문과 주기는 제조 AI의 현장 정착을 확인하기 위한 실무 제안이며, 인용 표준이 별도로 정한 의무 점검 주기나 통과 점수가 아닙니다. 사건이 없을 때는 0건 기록과 점검 또는 안전한 훈련의 수행 여부로 O/X를 판단합니다. 현장 사용이 없는 경우에는 기능 유형과 예정된 사용 상황도 함께 기록하고 판단합니다.
